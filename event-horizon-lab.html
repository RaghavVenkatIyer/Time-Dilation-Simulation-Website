Formulas used
same as the script

    

      
Schwarzschild radiusr_s = 2GM / c²

      
Time dilationt_faller = t_viewer · √(1 − r_s/r)

      
Escape velocityv_esc = √(2GM / r)

      
Gravitational accelerationg = GM / r²

      
Orbital velocityv_orb = √(GM / r)

      
Gravitational redshiftz = 1/√(1 − r_s/r) − 1

      
Compressed lengthL_faller = L_viewer · √(1 − r_s/r)

      
Gravitational potential energyU = −GmM / r

      
Hover accelerationa = GM/r² · √(1 − r_s/r)As written in the script. Textbook GR divides by √(1 − r_s/r) instead, which grows without limit near the horizon.

      
Orbital periodT = 2π √(r³ / GM)

      
Tidal accelerationΔa = 2GMh / r³

    

  


  
Newtonian formulas (escape velocity, orbital velocity and period, tidal force) are exactly as in the original script. Real orbits are only stable outside 3 rs, and light can circle the hole at 1.5 rs; the picture marks the disk from 3 rs outward for that reason.
